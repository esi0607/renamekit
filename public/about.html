파일명 바꾸기

사이트 소개

최종 수정 2026년 10월 28일

RenameKit은 파일명을 한 번에 바꾸는 무료 웹 도구입니다. 압축 파일을 올리면 규칙에 따라 이름을 바꿔서 새 압축 파일로 돌려줍니다.

왜 만들었나

파일 이름을 정리하는 일은 자주 필요한데, 쓸 만한 방법이 마땅치 않습니다.

  • 윈도우 탐색기의 일괄 이름 바꾸기는 접두어와 번호만 다룰 수 있어서, Screenshot_ 같은 앞부분을 조건부로 지우지 못합니다.
  • 파워셸은 강력하지만 명령어를 외워야 하고, 한 번 잘못 실행하면 되돌리기 어렵습니다.
  • 전용 프로그램은 설치가 필요합니다. 회사 PC나 학교 PC에서는 설치 자체가 막혀 있는 경우도 많습니다.
  • 온라인 파일 변환 사이트는 대부분 파일을 서버로 업로드합니다. 사진이나 문서를 남의 서버에 올리는 건 찝찝한 일입니다.

그래서 설치도 없고, 업로드도 없고, 미리보기로 실수를 막아주는 도구를 만들었습니다.

어떻게 동작하나

서버가 없습니다. 사이트 전체가 정적 파일(HTML·CSS·자바스크립트)로만 이루어져 있고, 모든 계산은 여러분의 브라우저에서 실행됩니다.

  1. 읽기 — zip 파일을 브라우저 메모리로 읽고, 압축을 풉니다. 이때 파일명 인코딩을 확인해서 CP949로 저장된 한글 이름도 복원합니다.
  2. 계산 — 규칙 목록을 파일마다 차례로 적용해 새 이름을 만듭니다. 이 단계는 화면과 무관한 순수 함수라서, 결과가 항상 같습니다.
  3. 쓰기 — 새 이름으로 zip을 다시 만들어 다운로드합니다. 원본 zip은 손대지 않습니다.

파일이 브라우저를 떠나는 시점은 여러분이 다운로드 버튼을 눌러 파일을 저장할 때 뿐이고, 그 저장 위치는 여러분의 컴퓨터입니다.

안전한 이유

"서버로 안 보낸다"는 말은 검증할 수 있어야 의미가 있습니다. 확인 방법은 간단합니다.

  • 브라우저 개발자 도구(F12)의 네트워크 탭을 연 상태로 파일을 넣고 이름을 바꿔보세요. 파일 크기만큼의 요청이 나가지 않습니다.
  • 페이지를 연 뒤 인터넷을 끊고 사용해보세요. 이름 변경과 다운로드가 그대로 동작합니다.
  • 사이트 코드는 압축 라이브러리까지 모두 이 사이트에서 직접 제공합니다. 외부 CDN에서 스크립트를 불러오지 않습니다.

한계

정직하게 알려드립니다.

  • zip만 지원합니다. 7z, rar, alz는 열 수 없습니다.
  • 브라우저 메모리를 씁니다. 대략 500MB 이하를 권장하고, 4GB가 넘는 ZIP64 형식은 지원하지 않습니다.
  • 파일 내용은 바꾸지 않습니다. 이름만 바꾸는 도구입니다. 이미지 변환이나 문서 편집 기능은 없습니다.
  • 암호가 걸린 zip은 열 수 없습니다. 미리 압축을 풀어 주세요.
  • 사진의 촬영 날짜를 읽어서 자동으로 이름을 정하는 기능은 아직 없습니다. 날짜 규칙은 오늘 날짜나 직접 지정한 날짜만 씁니다.

만든 사람

이 사이트는 RenameKit 운영자가 개인적으로 만들고 운영합니다. 특정 회사나 단체와 관련이 없으며, 파일을 보관하거나 열람하지 않습니다.

운영 비용은 사이트에 표시되는 광고 수익으로 충당합니다. 광고가 불편하시면 광고 차단기를 쓰셔도 도구 기능에는 아무 영향이 없습니다.
