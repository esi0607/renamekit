파일명 일괄 변경 사용법

최종 수정 2026년 10월 28일 · 읽는 시간 약 8분

사진 300장, 회의 자료 50개, 납품 파일 80개의 이름을 하나씩 바꾸고 있다면 손목이 먼저 망가집니다. 이 문서는 RenameKit으로 그 작업을 5분 안에 끝내는 방법을 순서대로 설명합니다.

1. 준비: zip 하나로 모으기

이 도구는 zip 파일을 받아서 zip 파일로 돌려줍니다. 이름을 바꾸고 싶은 파일들을 한 폴더에 모은 뒤 zip으로 압축하세요.

윈도우

파일을 모두 선택 → 마우스 오른쪽 버튼 → 보내기 → 압축(zip) 폴더. 또는 선택 후 압축 → ZIP 파일.

맥

파일을 모두 선택 → 마우스 오른쪽 버튼 → 압축. 선택한 항목들이 아카이브.zip 하나로 묶입니다.

폴더째 넣어도 됩니다. zip 안에 하위 폴더가 있으면 그 구조를 유지한 채 파일 이름만 바뀝니다. 예를 들어 사진/IMG_0001.jpg는 사진/photo_001.jpg처럼 폴더는 그대로 남습니다.

zip 없이 파일만 끌어다 놔도 됩니다. 이 경우 결과는 zip 하나로 묶여서 내려받아집니다.

2. 3단계 사용법

1단계 — 파일 넣기

메인 화면의 점선 상자에 zip을 끌어다 놓거나 파일 선택 버튼을 누르세요. 파일은 브라우저 메모리에서만 처리되고 어디로도 전송되지 않습니다. 그래서 인터넷이 끊겨도 동작합니다.

2단계 — 규칙 정하기

빠른 시작 버튼 8개 중 하나를 누르면 아래 규칙 칸이 자동으로 채워집니다. 그대로 눌러도 되고, 숫자나 글자만 고쳐도 됩니다. 규칙은 위에서부터 차례대로 적용되므로, 순서를 바꾸면 결과도 달라집니다.

3단계 — 확인하고 내려받기

미리보기 표에서 변경 전 / 변경 후 / 상태를 한 줄씩 비교하세요. 문제가 있으면 그 줄에 확인 또는 오류 표시가 붙습니다. 만족스러우면 이름 바꾼 zip 다운로드를 누르면 끝입니다.

원본은 절대 바뀌지 않습니다. 다운로드되는 것은 이름이 바뀐 사본이 담긴 새 zip입니다. 잘못 바꿨으면 원본 zip을 다시 넣고 규칙만 고치면 됩니다.

3. 규칙 12가지

규칙 칸의 드롭다운에서 고를 수 있는 항목입니다.

규칙하는 일예시
앞에 붙이기 이름 맨 앞에 글자를 붙입니다. a.jpg → 2026_a.jpg
앞부분 지우기 정해진 글자로 시작하면 그 부분을 지웁니다. IMG_2847.jpg → 2847.jpg
글자 수로 지우기 앞 또는 뒤에서 몇 글자를 지웁니다. 값이 규칙적이지 않을 때 유용합니다. Screenshot_2026_10.png → 2026_10.png
뒤에 붙이기 이름 맨 뒤(확장자 앞)에 글자를 붙입니다. 보고서.docx → 보고서_최종.docx
뒷부분 지우기 정해진 글자로 끝나면 그 부분을 지웁니다. 보고서_복사본.docx → 보고서.docx
찾아서 바꾸기 특정 글자를 다른 글자로 바꿉니다. KakaoTalk_ → (빈칸)
번호 매기기 순서대로 번호를 붙입니다. 자릿수와 시작 번호를 정할 수 있습니다. photo_001, photo_002 …
날짜 형식 통일 오늘 날짜나 고정 날짜를 붙입니다. 형식은 3가지. 2026-10-28, 20261028, 261028
안전한 문자로 정리 공백·특수문자를 밑줄이나 하이픈으로 바꿉니다. 최종 보고서 (1).docx → 최종_보고서_1.docx
대소문자 전부 소문자 또는 전부 대문자로 바꿉니다. IMG_0001.JPG → img_0001.jpg
확장자 변경 확장자만 바꿉니다. 이름 부분은 건드리지 않습니다. a.jpeg → a.jpg
길이 자르기 이름이 너무 길 때 뒤를 잘라냅니다. 60자 → 40자

미리보기 정렬: 자연순 vs 원본순

미리보기 오른쪽 위의 토글로 표시 순서를 바꿀 수 있습니다.

  • 자연순 — 사람이 보기 좋은 순서. 1, 2, 3, …, 10. 기본값입니다.
  • 원본순 — zip 안에 실제로 저장된 순서. 압축 프로그램이 만든 순서를 그대로 보여줍니다.

번호 매기기 규칙은 화면에 표시된 순서를 따릅니다. 그래서 원본순일 때와 자연순일 때 번호가 다르게 붙을 수 있습니다. 사진 순서를 맞추고 싶다면 자연순이 거의 항상 정답입니다.

4. 실전 예시 4가지

예시 1 — 휴대폰 사진을 순서대로 정리

IMG_2847.jpg부터 IMG_3100.jpg까지 254장이 있다고 가정합니다.

  1. 사진을 한 폴더에 모아 zip으로 압축
  2. 빠른 시작에서 사진 순번 매기기 클릭
  3. 접두어를 여행_으로 수정
  4. 결과: 여행_001.jpg, 여행_002.jpg …

원본 파일명이 뒤죽박죽이어도 자연순 정렬이 숫자를 크기대로 읽기 때문에 IMG_999가 IMG_1000보다 앞에 오는 사고가 없습니다.

예시 2 — 캡처·카카오톡 접두어 제거

Screenshot_2026-10-28-143022.png 같은 이름에서 앞부분을 잘라냅니다.

  1. 앞부분 지우기 규칙 선택
  2. 값에 Screenshot_ 입력
  3. 결과: 2026-10-28-143022.png

카카오톡은 KakaoTalk_20261028_143022123.jpg처럼 붙입니다. 찾아서 바꾸기로 KakaoTalk_를 빈칸으로 바꾸면 됩니다.

예시 3 — 납품 전 군더더기 정리

최종 보고서 (1).docx, 최종 보고서 (2).docx 같은 이름은 받는 쪽에서 헷갈립니다. 규칙 두 개를 이어 붙이세요.

  1. 안전한 문자로 정리 — 공백과 괄호를 밑줄로
  2. 번호 매기기 — 자릿수 2, 접두어 보고서_

결과: 보고서_01.docx, 보고서_02.docx …

예시 4 — 웹에 올릴 파일명을 안전하게

한글·공백·#, ? 같은 문자는 URL에서 깨지거나 잘립니다.

  1. 안전한 문자로 정리
  2. 대소문자 → 소문자
  3. 확장자 변경 → jpg

결과는 product_main_01.jpg처럼 어디서나 안전한 형태가 됩니다.

5. 다른 방법과 비교

방법장점한계
윈도우 탐색기 일괄 이름 바꾸기 설치 없이 F2로 바로 접두어·번호만 가능. 확장자·조건부 삭제 불가
파워셸 Rename-Item 무한히 유연 명령어를 알아야 하고, 실수하면 되돌리기 어려움
엑셀로 목록 만들어 복사 규칙을 눈으로 확인 가능 파일명 복사·붙여넣기 과정에서 확장자 사고가 잦음
전용 프로그램 설치 기능이 많음 설치·광고·라이선스 부담. 회사 PC에서는 설치 자체가 문제
RenameKit 설치 없음, 미리보기로 실수 방지, 서버 전송 없음 브라우저 메모리 사용 (500MB 이하 권장)

6. 자주 하는 실수

실수 1 — 확장자까지 바꿔버림

찾아서 바꾸기로 .을 지우면 확장자까지 사라져서 파일이 열리지 않습니다. 확장자는 반드시 확장자 변경 규칙으로만 다루세요. 미리보기 표에서 확장자가 사라진 줄이 있으면 즉시 알 수 있습니다.

실수 2 — 규칙 순서를 반대로 넣음

번호 매기기 뒤에 앞부분 지우기를 넣으면 방금 붙인 번호가 지워집니다. 규칙은 위에서 아래로 적용된다는 점을 기억하세요.

실수 3 — 이름이 중복됨

규칙을 잘못 넣어 두 파일이 같은 이름이 되면 미리보기에 오류로 표시됩니다. 이 상태로 내려받으면 하나가 사라질 수 있으니, 반드시 오류 표시가 없는 상태에서 다운로드하세요.

안전 장치: 원본 zip은 그대로 남습니다. 이름이 꼬였으면 원본으로 다시 시작하면 되고, 다운로드한 결과물만 지우면 됩니다.
