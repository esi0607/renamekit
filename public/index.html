파일명 일괄 변경

zip 파일이나 파일들을 끌어다 놓고 규칙을 고르면, 이름을 한 번에 바꿔서 돌려드립니다. 설치 없이 브라우저에서만 동작합니다.

zip 파일을 여기로 끌어다 놓으세요

zip 안의 파일을 이름만 바꿔서 새 zip으로 돌려드립니다. zip이 없으면 파일을 그대로 끌어다 놔도 됩니다.

파일은 브라우저 밖으로 나가지 않습니다.

빠른 시작

버튼을 누르면 아래 규칙이 자동으로 채워집니다. 그대로 쓰거나 값을 고쳐서 쓰세요.

규칙

규칙은 위에서부터 차례대로 적용됩니다. 확장자는 '확장자' 규칙으로만 바꿉니다.

미리보기

파일을 넣으면 여기에 변경 결과가 표시됩니다.

원본 파일은 그대로 남습니다. 사본이 담긴 새 zip을 받습니다.

  1. 1. 파일 넣기

  2. 2. 규칙 정하기

    프리셋을 누르거나 규칙을 직접 추가하세요. 결과는 아래 표에서 바로 확인됩니다.

  3. 3. 내려받기

    이름이 바뀐 파일이 담긴 새 zip을 받습니다. 원본은 손대지 않습니다.

자주 묻는 질문

파일이 서버로 올라가나요?

아니요. 압축 해제와 이름 변경, 다시 압축하기까지 전부 브라우저 안에서 처리됩니다. 네트워크 전송이 없습니다.

한글 파일명이 깨지지 않나요?

윈도우에서 만든 zip은 파일명을 CP949로 저장하는 경우가 있습니다. 이 도구는 UTF-8 표시가 없으면 CP949로 다시 읽어서 한글이 깨지지 않게 처리합니다.

폴더 구조는 유지되나요?

네. zip 안의 폴더 구조는 그대로 두고 파일 이름만 바꿉니다.

얼마나 큰 파일까지 되나요?

브라우저 메모리를 쓰기 때문에 대략 500MB 이하를 권장합니다. 그보다 크면 느려지거나 실패할 수 있습니다.
